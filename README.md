# Priora

> Stay focus, on what matters.

Un gestionnaire de tâches façon Kanban, développé en JavaScript vanilla.
Projet personnel, pensé pour être simple, rapide et sans dépendance.

**[Démo en ligne](https://remipierre.github.io/Priora/)**

---

## Fonctionnalités

- Création et gestion de plusieurs tableaux (*boards*)
- Colonnes **To-Do / In Progress / Done**
- Création, édition et suppression de cartes
- Tout est sauvegardé automatiquement dans le `localStorage` du navigateur —
  aucun serveur, aucune base de données nécessaire

---

## Stack technique

HTML / CSS / JavaScript vanilla, sans framework ni dépendance externe.

---

## Lancer le projet en local

```bash
git clone https://github.com/RemiPIERRE/Priora.git
cd Priora
# ouvrir index.html dans un navigateur, aucune installation nécessaire
```
